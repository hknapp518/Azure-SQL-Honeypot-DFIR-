# Azure SQL Honeypot — Detection Engineering & DFIR

An Azure security project designed to capture and investigate real-world attacks against an intentionally exposed Windows/MySQL honeypot.

The environment uses Microsoft Defender for Endpoint, Microsoft Sentinel, Azure Monitor Agent, Log Analytics, custom MySQL telemetry, and KQL detections to observe authentication activity and database interaction.


## Project Status

**Phase 1** — Windows honeypot deployed
**Phase 2** — MySQL deployed and populated with synthetic corporate data
**Phase 3** — MySQL telemetry ingested into Log Analytics
**Phase 4** — Sentinel detections deployed and validated
**Phase 5** — Controlled exposure
**Phase 6** — Breach detection
**Phase 7** — Threat hunting and investigation
**Phase 8** — Containment
**Phase 9** — Eradication and recovery
**Phase 10** — DFIR reporting
